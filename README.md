# 🚗 Carpooling Fullstack Application

## Overview
A full-stack web application designed to connect commuters for shared rides, making travel more affordable and eco-friendly. The system supports secure user authentication, real-time ride booking, and location tracking functionalities.

## Features
- User registration and login with secure authentication
- Ride booking and ride-sharing interface
- Real-time location tracking and ride status updates
- MongoDB-powered backend for fast and scalable data storage
- Responsive design for both desktop and mobile

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Tools**: Postman, Git

## Project Structure
📁 client/ # Frontend files (HTML/CSS/JS)
📁 server/ # Backend files with Express and routes
📄 .env # Environment variables (not included)
📄 server.js # Main server file
📄 README.md # Project documentation


## Installation

1. **Clone the Repository**
git clone https://github.com/satishsat1/carpooling-fullstack.git
cd carpooling-fullstack
2.Install Server Dependencies
cd server
npm install
3.Start the Server
node server.js
4.View Frontend
Open the client/index.html file in your browser or use a local server to serve static files.
